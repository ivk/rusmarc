RUSMARC
=======

Установка
---------

Нужен Python 3. Сторонних зависимостей нет: ``requirements.txt`` пустой,
для работы достаточно стандартной библиотеки.

Из каталога проекта::

    pip install -e .

После этого импортируется пакет ``rusmarc``. Скрипт ``read.py`` в пакет
не входит и запускается из корня репозитория.

База SQLite отдельно пользователем не создаётся. 
При запуске  ``read.py`` с флагом ``-d`` она создается автоматически, в корне репозитория в каталоге ``db/`` с именем ``rusmarc.db``.
Таблица внутри базы называется по имени файла или каталога, который передан в команду. В имени таблицы допустима только латиница: имя подставляется в SQL как есть, без кавычек. 


Запуск
------

Из корня репозитория::

    python read.py путь/к/файлу.iso


Аргументы:

``filename``
    Файл или каталог. Если передан каталог, читаются только файлы в нём,
    без вложенных папок. Флаги ``-f`` и ``-b`` в этом режиме отключаются.

``-enc``, ``--encoding``
    Кодировка полей: ``UTF-8`` (по умолчанию), ``cp1251`` или ``cp866``.

``-d``, ``--save_db``
    Записать разобранные записи в ``db/rusmarc.db``.

``-f``, ``--save_file``
    Дописать каждую успешно прочитанную исходную запись в
    ``marcfiles/newmarc.iso``. Файл при старте удаляется и создаётся заново.

``-b``, ``--save_bad_records``
    Сложить сырые байты записей, которые итератор или разбор счёл
    повреждёнными, в ``marcfiles/corrupted.iso``.

Ошибки разбора дописываются в ``corrupted.log`` в корне репозитория.
В конце печатается число записей и ошибок, список номеров полей и образец
значения из первой успешной записи. Для части номеров подставляется
название из словаря ``standard_fields`` в ``read.py`` (ISBN, заглавие,
автор, УДК и другие часто встречающиеся поля RUSMARC). Незнакомый номер
подписывается как ``unknown field``.
